# 用語集（画面・レポートに出る語）

**この表は「画面とレポートに出る名詞のうち、二義になり得るものだけ」を載せる。**
網羅はしない——維持できない正典は、いずれ嘘になるほうが速い。

- **対象**＝利用者の目に触れる字（`i18n.py` の ja/en 文字列）。
- **対象外**＝コード内部の識別子・`i18n` のキー名・`{…}` の差し込み名・
  CSV の列名やファイル名（**出力契約**なので、読む側の互換のほうが優先する）。
  実装語彙と画面語彙は別物で、揃えようとすると改名の波及リスクだけが増える。

**この表は `tests/test_i18n_glossary.py` が機械で守る**（散文の決めごとは静かにずれる）。
語を変える／足すときは、表と `i18n.py` を同じコミットで動かすこと。

**表の列見出しだけは、幅が語に優先する**（2026-08-07・スライス D で決定）。
`送信高` / `受信高` は `アンテナ高` の短縮形として読める——**同じ語の短縮**は許すが、
**別の語への言い換え**（`地上高`）は許さない。⚠️ 短縮形は「使わない言い換え」欄には
書かない（書くと列見出しのほうが赤くなる）。

**成果物（レポート HTML）の語は、画面の語と食い違うことがある。**
`html_batch_mode` / `html_batch_title` は `一括シミュレーション` のまま——**出力契約**
なので、読む側の互換を画面の都合で壊さない。⇒ **画面の名前と成果物の名前を揃えるのは
3.2（出力契約）の仕事**。⚠️ このため `一括シミュレーション` は「使わない言い換え」に
載せていない（載せた瞬間、触らないと決めた成果物側が赤くなる）。

## 表の読み方

| 列 | 意味 |
|---|---|
| **用語** | 日本語の画面でこの意味に使う唯一の語 |
| **定義** | 何を指すか。数量なら**何を数えるか**まで書く |
| **en** | 英語の画面で対応させる語 |
| **使わない言い換え** | 同じものを指してしまいがちな語。**画面に出したら失敗**（`/` 区切り） |

## 用語

| 用語 | 定義 | en | 使わない言い換え |
|---|---|---|---|
| 区間 | 中継経路で隣り合う 2 地点を結ぶ 1 本の回線。数えるのは**リンクの本数**＝「地点数 − 1」。区間ごとに独立したリンクバジェットを持つ | Section | ホップ / hop |
| 地点 | 中継経路が通る点すべて（送信点・中継点・受信点）。利用者が入力する面はこちらで、区間はここから導かれる | Waypoint | ノード / node |
| 中継点 | 地点のうち、送信点でも受信点でもないもの | Relay | リレー |
| マージン | 受信レベル − 受信感度（dB）。正なら OK | Margin | 余裕度 |
| 受信レベル | 受信アンテナ利得まで含めた、受信端に届く電力（dBm） | RX Level | 受信強度 / 電界強度 / RSSI |
| 受信感度 | 判定の基準にする受信レベルの下限（dBm）。機器のカタログ値を利用者が入れる | Threshold | 閾値 / しきい値 |
| 判定 | OK / NG / ERR の 3 値。OK・NG は**マージンの符号**で決まり、ERR は**計算か成果物の生成に失敗して判定できなかった**ことを表す（レポートでは `ERROR`） | Status | ステータス |
| 全体判定 | 中継経路ぜんたいの判定。**最もマージンの小さい区間の判定**がそのまま全体になる（区間をまたいで損失は足さない）。判定できなかった区間（ERR）が 1 つでもあれば OK にはならない | Overall | 総合判定 |
| 斜距離 | 送受アンテナ間の距離（**高低差を含む**） | Slant Dist | 直線距離 |
| 水平距離 | 送受地点を地表へ投影した距離（**高低差を含まない**） | Horiz Dist | 地表距離 |
| 総損失 | FSPL・回折・植生・環境・降雨・大気の各損失の合計（dB） | Total Loss | 伝搬損失 |
| 環境区分 | 環境損失を決める 4 択（市街地 / 郊外 / 農村 / 見通し） | Env Type | 地域区分 / 環境タイプ |
| 植生高 | 地表からの植生の高さ（m）。経路全体へ一律に与える | Vegetation Height | 樹高 |
| F1遮蔽率 | 第 1 フレネルゾーンの断面のうち、地形・植生に遮られた割合（%） | F1 Obs | フレネル遮蔽率 |
| 地形サンプル数 | 経路上で標高を取る点の数。多いほど細かいが、取得は重くなる | Sampling Points | 標本数 / 分解能 |
| 経路 | 送信点から受信点までの 1 本のつながり。中継経路なら途中の中継点も含む | Path | Route |
| アンテナ高 | 地表からアンテナまでの高さ（m）。**地物の高さではない**（→ 植生高） | Antenna Height | 地上高 |
| 複数経路 | N 本の**独立した**回線をまとめて回す窓。1 行 = 1 経路（→ 中継経路は 1 本の内訳） | Multiple Paths | バッチ |
| 地図 | 座標を拾い、DEM キャッシュを見るための補助の窓。**入力の道具**であって実行フローではない | Map | マップウィンドウ |

## この表ができた経緯

2026-08-01 に、**同じものを 2 語で呼んでいた**欠陥が 1 セッションで 4 件出た。
そのうち「区間」は、数字（リンクの本数）が正しいのに**語だけが別の量として伝わる**
という形の表記バグで、2.6b で `ホップ` → `区間` へ直した。
残りは語彙の回（2.7）でまとめて直す。

**1 か所だけ直すと語彙が 3 通りに増える**——だから直したあと、語の統一を機械で縛る。
