# experiments/ — 判断の根拠を再実行できる形で残す置き場

**製品コードではない。** ここのスクリプトはアプリのどのモジュールからも import されず、
配布物（`radiosim.spec`）にも含まれない。CI の型検査・カバレッジの対象外（`ruff` だけは
リポジトリ全体を見るので構文と体裁は保つ）。

## なぜ残すのか

設計判断の根拠が「あのとき計算した」という記憶だけになると、**後から前提を変えて
再判定できない**。判断を覆す条件（周波数・アンテナ高・距離）を入れ直せる形で置いておく。

実行:

```
python experiments/phase0_two_ray.py
```

⚠️ **`b119_*_probe.py` の 2 本と `tk9_dpi_probe.py` だけは例外**＝GUI を建てて**人が表示スケールを変え、窓を
ドラッグする**探針で、実機でしか意味を持たない（それ以外は純計算＝ネットワーク・GUI・
ファイル書き込みなし）。⚠️ 2 画面は要らない＝**1 枚でスケールを変えれば再現する**
（デュアル DPI 前提は 2026-08-23 に棄却済み）。結論は課題台帳の該当項目が正典。

物理・設計判断の側（`phase0_*`）は、結論の全文とそこから決まった設計方針を
memory の `project-radiosim-for-drone` / `project-radiosim-tracer` が持つ。
