# experiments/ — 判断の根拠を再実行できる形で残す置き場

**製品コードではない。** ここのスクリプトはアプリのどのモジュールからも import されず、
配布物（`radiosim.spec`）にも含まれない。CI の型検査・カバレッジの対象外（`ruff` だけは
リポジトリ全体を見るので構文と体裁は保つ）。

## なぜ残すのか

設計判断の根拠が「あのとき計算した」という記憶だけになると、**後から前提を変えて
再判定できない**。判断を覆す条件（周波数・アンテナ高・距離）を入れ直せる形で置いておく。

## 一覧

| スクリプト | 何を判定したか | 実行日 |
|---|---|---|
| [phase0_two_ray.py](phase0_two_ray.py) | 2 波干渉（地面反射）が対空リンクで無視できるか＝**段階 0（机上判定）**。結論＝棄却できない／効くのは GCS 前方 3〜80m の地表／ヌルの「位置」は予測不能で予測すべきは振幅の包絡線 | 2026-07-26 |
| [phase0_survey_accuracy.py](phase0_survey_accuracy.py) | **離陸点の測量精度 ±N m** が余裕度を何 dB 動かすか＝RadioSim Tracer の精度目標の逆算。ゴールデンコーパス 26 本（かすめ帯を含む）から再計算するのでネットワーク不要。結論＝回折が効く回線の勾配は **1.3〜1.7 dB/m**・見通し回線は 0 dB/m ⇒ **±0.25 m（目標 0.3 dB）／±0.65 m（上限 1.0 dB）**＝単独測位 GNSS では 1〜2 桁足りず、離陸点で一度だけ RTK 級が要る | 2026-08-02 |
| [font_fallback_probe.py](font_fallback_probe.py) | 日本語の書体が本当に揃っているか＝`font actual … -- 漢` で**実際に描かれる書体**を測る（バッチ表の見出しだけ別書体になる不具合の調査用）。結論＝Segoe UI Variable 系は漢字をフォントリンクに逃がし、太字では Malgun Gothic（韓国語）へ落ちる／ja の本文を Yu Gothic UI にすると全用途で一致 | 2026-07-31 |
| [b119_frame_slip_probe.py](b119_frame_slip_probe.py) | **別 DPI のモニタへ移した窓が 6px ずつ縮み続けるのは誰の仕業か**。`wm geometry` を呼んだ者を呼び出し元つきで記録するので、**Python が書いたのか Tk/WM が縮めたのか**が 1 回で分かる。結論＝Tk は移る前の DPI の枠の厚みを持ったままで、要求より 6px 狭い窓を返す／`need > 実幅` が永久に成立して自励ループになる／**ドラッグ中かどうかは無関係** | 2026-08-23 |
| [review_benchmark/](review_benchmark/) | **独立レビューのベンチマーク**＝Codex が実際に出した指摘 11 件（全件真）＋対照の偽陽性 1 件に、裏取り済みの正解ラベルを付けたもの。**レビュアーを入れ替えたとき（ローカル LLM に託せるか等）に同じ物差しで測る**ため。コード面は git で完全再現・文書面は復元手順つき | 2026-07-26 |

実行:

```
python experiments/phase0_two_ray.py
```

⚠️ **`b119_frame_slip_probe.py` だけは例外**＝GUI を建てて**人が窓をドラッグする**探針で、
別 DPI の 2 画面がある実機でしか意味を持たない（それ以外は純計算＝ネットワーク・GUI・
ファイル書き込みなし）。結論の全文と、そこから
決まった設計方針は memory の `project-radiosim-for-drone` が正典。
