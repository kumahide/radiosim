## 手順

1. 前の引き継ぎ書の「目標」と「次の一手」から続ける。進み具合の正典は版計画のステージ行と台帳（`python .claude/ledger.py roadmap <版>`・`issue <ID>`）。
2. ステージごとにコミットし、push まで進める（任されている）。
3. 判断が要るときは推測せず、AskUserQuestion で選択肢を出して待つ（人は VS Code か Remote Control から答える）。
4. トークン予算の助言（リレー）が来たら、いまの一手を閉じてコミット・push し、台帳と版計画の途中経過を書き、引き継ぎ書を `status: continue` で書いて応答を終える。
5. 目標のステージまで済んだら、引き継ぎ書を `status: done` で書いて応答を終える。

## 規則

- 目標の外へ出ない。版の節目（a→b の前方見直し・RC・正式・/release）は範囲に入れない。
- 引き継ぎ書を書いた後は何もしない（リレーがこのセッションを止めて次を起こす）。
- フルスイートは回さない（コミット前ゲートの範囲だけ）。
